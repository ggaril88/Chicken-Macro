# Chicken Macro

A compact Windows macro recorder and player.

## Features

- Record keyboard input, mouse clicks, and optional mouse movements.
- Create multiple macros with individual keyboard shortcuts.
- Adjust playback speed and repeat count.
- Insert pauses and edit action delays in milliseconds.
- Optional status sounds and administrator access.

## Project status

Preparing the first Windows release. No official executable is available yet.

## Responsible use

Use Chicken only where automation is permitted. Games and services may
restrict macros or take action against accounts that use them.

You are responsible for checking the rules of the apps you use.

## Known limitation

Holding Ctrl during playback can change the meaning of a macro's keystrokes.
Use a single key, such as F10, as your Stop shortcut to avoid this conflict.
